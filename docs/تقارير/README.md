# تقارير

## الهدف الواجب الوصول إليه

تجميع بيانات كل الأقسام في **تقارير محاسبية وتشغيلية** قابلة للطباعة والتصدير واتخاذ القرار.

## النتيجة المرجوة

- مركز تقارير (`/reports`) بكل التقارير المصنّفة
- مقارنة فترات وتصدير PDF/Excel
- تقارير لكل قسم (مواد، سندات، CC…)

## العلاقات

### يعتمد على

- كل الأقسام التي تُنتج بيانات

### يغذّي

- الإدارة، [مقدمة](مقدمة/README.md) (لوحة تحكم)

## الحالة الحالية

| البند | القيمة |
|--------|--------|
| النضج | 🟡 جزئي |
| التقدم | ~65% |
| آخر تحديث | 2026-07-26 |

**موجود:** hub تقارير (`/reports`) بـ9 تقارير فعلية — ميزان مراجعة، كشف حساب، أعمار ذمم، ذمم عملاء/موردين، مبيعات/مشتريات تفصيلي، ملخص حركات مخزون، رصيد مخزون، COGS — بالإضافة لطباعة من المتصفح وتصدير CSV. مُدقَّقة بالكامل (`audit-reports/2026-07-25-*.md`) وأغلب الأخطاء الحرجة المكتشفة (خلط عملات، أعمدة كلفة/إيراد خاطئة، فشل بنيوي بربط الأطراف) عولجت فعلياً بالكود (`patch_reports_audit_fix.sql`, `patch_reports_audit_fix2.sql`, 2026-07-26). تبقى فجوات ثانوية بمعظمها: لا فحص صلاحية على مستوى RPC بأغلب التقارير، لا Limit على بعض الاستعلامات، بعض التقارير بلا تصدير CSV/طباعة. غير موجود بعد: تقرير السندات، تقرير مراكز الكلفة، تقرير تصنيفات الأسطر، مقارنة فترتين، تصدير PDF بقوالب مخصّصة.
